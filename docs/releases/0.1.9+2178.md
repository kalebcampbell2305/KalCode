# KalCode 0.1.9 (build 2178)

Source commit: `7ca5ac736bebcedb086598297da39083b7367331`.

## New in this build

- **Squads: launch a whole team of coding agents at once.** Save a reusable team in Code > Squads or Operations > Squads. Pick each member's provider account, model and effort, and optionally add roles, tasks, the files each one owns, who waits on whom, and a manager. Launch opens every member as a real coding terminal, the same one you get from New agent. A member that depends on other work opens right away and shows Waiting; its task is sent only once that work succeeds. If an account isn't available, only that member is held, with a reason you can act on, and the rest of the team keeps going. Save a Squad Recipe to relaunch a team with a new goal, or say "launch Engineering squad" or "run Review recipe" to KalVoice. When the team finishes, KalCode says Agents done, not Shipped, until there's real evidence the changes landed. Squads are part of MAX.
- **New agent shows the right models for each account.** New agent and the Squad editor now list the models each signed-in account can actually use. Codex lists its own models with the effort levels each one supports. A model you picked stays selected even if the list can't be refreshed.
- **The Mac Browser pane no longer gets stuck.** On macOS, a Browser pane whose first page fails to load no longer spins forever, and embedded frames (video, payment, sign-in) no longer replace the pane's address.

## Platforms

- Windows 10 version 1809 or later, x64.
- macOS 14 or later, Apple silicon.
