# KalCode 0.1.9 (build 1450)

Source commit: `48eb9f8ba9f699b4d47d5b6a81b7677b415b3705`.

## New in this build

- **Code is the daily workspace.** Saved workspaces open into Code, where Claude Code, Codex and
  Gemini CLI agents run as independent real provider terminals. Launching several agents creates
  that many fresh sessions in the current workspace, and Agent Fleet focuses those same panes.
- **Working context stays beside the code.** Browser, Runs, Services, Tests, Needs You, widgets and
  other workspace context remain close without page hopping. Provider account, model, effort and
  permission selections continue through the existing provider-native session paths.
- **Live Browser joins Code.** Open detected local, preview and production targets beside an agent;
  inspect bounded console and load errors; pick an element; capture a screenshot; and send the page,
  selected element, errors and screenshot to a chosen coding agent as clearly labelled untrusted
  page context. Sign-in pop-ups stay outside the embedded browser and can continue in the system
  browser. KalCode does not collect website credentials.
- **Provider usage is fresher.** Claude Code and Codex account usage can refresh from each
  provider's read-only usage endpoint when existing readings are old. If a refresh is unavailable,
  KalCode keeps the last known reading and shows its freshness.
- **Updates arrive during long sessions.** While KalCode stays open on Windows or macOS, the signed
  Stable feed is checked about every ten minutes with jitter so a new build can download and stage.
  On Windows, shutdown or sign-out no longer counts as a skipped silent update; the staged build
  remains ready for the next normal quit.
- **Faster cleanup and recovery.** KalTidy can clear failed agents, clear finished agents, or close
  all terminals and agents from Code. Reopen restores a closed terminal pane's slot, while the
  closed process remains ended.
- **Small daily actions take fewer steps.** New agent is first in the command palette, Provider
  Health shows the account's real sign-in state and offers Check now, empty workspace selection
  opens the folder picker, and common onboarding, update, Operations, project and KalVoice errors
  now lead directly to their relevant recovery action.
- **Stronger Windows package integrity.** The release pipeline signs the NSIS temporary
  uninstaller and requires the installed uninstaller to be valid, timestamped and signed by the
  same publisher as the installer in every clean-install and upgrade verification pass.

## Platforms

- Windows 10 version 1809 or later, x64.
- macOS 14 or later, Apple silicon.
