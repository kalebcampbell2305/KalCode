# KalCode 0.1.9 (build 1992)

Source commit: `179617a61ec2879f90fbe4ee9a5f90e6a03b37d6`.

## New in this build

- **The top-bar search stays readable in narrow windows.** When the window was squeezed, the command field could shrink to a meaningless "S..." next to Ctrl K. The shortcut hint now hides first, the "Search" caption stays as long as it fits, and only then does the field fold into a search icon. Screen readers now announce it as "Search or run a command".
- **Chip values end with an ellipsis instead of being cut mid-word.** In narrower windows the Environment and Mode chips could show values like "Previe" or "Bypas". They now shorten cleanly with "...".

## Platforms

- Windows 10 version 1809 or later, x64.
- macOS 14 or later, Apple silicon.
