# KalCode 0.1.9 (build 1658)

Source commit: `bba3269adc672ecae7863396cb6c7eff84113cfa`.

## New in this build

- **Coding agents keep their native tools.** Claude Code and Codex inside KalCode can now search and fetch the web (including in Plan mode), use your own MCP servers, and run their shell, file and repo-search tools. Codex keeps web search, MCP servers, plugins and your own config.
- **Tool calls are no longer blocked when KalCode is busy.** If KalCode is busy, restarting or updating, a tool call falls back to the provider's own permission prompt instead of failing with "KalCode couldn't check this tool call".
- **Your setup follows every account.** Agents signed in to a provider account now see your own environment (SSH agent, `GH_TOKEN`, `JAVA_HOME`, cloud credentials, MCP secrets) and your native provider setup: settings, `CLAUDE.md`/`AGENTS.md`/`GEMINI.md`, agents, skills, plugins, commands and MCP servers. Sign-ins and account identity stay separate, so each account is still its own.
- **Codex and Gemini CLI work as they do in your terminal.** Codex uses your own `config.toml` and project trust, and Business, Enterprise and Edu accounts are no longer refused. Gemini CLI runs in your real workspace with your MCP servers, extensions and skills, and Plan uses Gemini's own plan mode.
- **Tool status you can trust.** The Providers page lists each provider's tools as native, needs setup, or not offered (with the reason). Coding panes show a compact indicator such as "TOOL - Search web - Running...".
- **Agents you start, start now.** A busy CPU no longer holds a new coding agent at "waiting for system resources". KalCode only waits when the machine genuinely cannot run it (very low memory, a full disk, or Windows refusing a new process), shows the real reason, and offers Start Anyway. Background work still yields first.
- **A new look, with high contrast and text size.** A refined graphite visual system across KalCode, plus new Contrast and Text size settings under Appearance.
- **Focus stays where you put it.** A terminal that finishes starting after you have moved on no longer takes the keyboard focus back.
- **The quick switcher finds workspaces by the name you gave them** in the sidebar, not only by folder name.

## Platforms

- Windows 10 version 1809 or later, x64.
- macOS 14 or later, Apple silicon.
