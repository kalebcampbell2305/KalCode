# KalCode 0.1.9 (build 1390)

## New since build 1340

- Adaptive Canvas adds Build, Debug, Review, Ship and Focus layouts to Code, with contextual suggestions you choose when useful. Manual arrangements stay in your control.
- Tidy arranges panes without stopping work. Undo restores the prior arrangement, including sizes, selected tabs and focus.
- Magnetic snap targets and live placement previews make moving panes predictable. Larger resize handles, keyboard movement and scrollable minimum pane sizes keep busy workspaces readable.
- Live terminals, coding agents, Browser and widgets keep their identity when moved, minimized, maximized or docked. Workspace focus returns with the saved layout.
- Context menus bring relevant pane and workspace actions to the place you are working.
- Codex coding terminals initialize their workspace execution host by default and surface execution failures instead of hiding them.

## Updating

The public version remains 0.1.9. Existing users receive this internal build through the signed production update feed. Normal updates preserve workspace and provider data.
