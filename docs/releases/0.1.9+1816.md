# KalCode 0.1.9 (build 1816)

Source commit: `c92188052cb160faf477ccc5c14ee93a99af2838`.

## New in this build

- **Project-centered navigation.** The sidebar now leads with Code, Activity (formerly the Dashboard) and your projects. Browser, Operations, Threads, KalVoice, Unified Memory, Providers and the rest move to a More menu at the bottom, the command palette still lists everything, and KalVoice understands "Open Activity".
- **One Needs You inbox.** Questions, approvals, recent failures, sign-outs, agents with no activity for 20 minutes and finished work to review now gather behind one Needs you button. Each item says what happened and why, with the next step: Open agent, Retry, Review or Sign in. Activity shows a one-line Needs You summary above the Fleet.
- **New agent in one click.** In Code, New agent starts the setup KalCode already knows - your remembered account, model and effort - in the current project, and its tooltip says exactly what will start. When there is a real choice to make, it opens the launcher instead, and the arrow beside it always opens the full options. One click starts one agent.
- **Weekly usage, front and center.** The usage percentage on agent and terminal headers, the Account + Usage Center and the launcher's account rows now shows how much of the account's weekly limit is left. If a provider doesn't report a weekly figure, it says "Weekly usage unavailable" instead of showing another number. The 5-hour and per-model limits stay in the expanded details, and a low-usage suggestion names the limit that is running low.
- **A faster Code tab with many agents.** Each agent's update now redraws only its own pane, an event refreshes only the pane it names, identical reads are shared, and the terminal cursor blinks without redrawing the page. Launching several agents at once starts them together in one batch.
- **Agents start faster, even when your computer is busy.** Starting an agent reuses a recent provider check instead of running the provider's version check again, and agents started together share one check. The first agent after KalCode opens no longer waits behind a second round of provider checks. Installing, upgrading, removing or signing out of a provider is still picked up on the next launch.
- **Your follow-ups are never held for a busy CPU.** A message you send to an agent that a scheduled operation started now counts as yours and starts right away, while scheduled work still waits. When a launch is held for a real reason, Start Anyway now appears on its agent card in Activity, next to that reason.
- **KalVoice knows your coding agents.** Asking KalVoice which agents are stuck, have failed or need you now includes your coding agents.
- **See what each agent's work amounted to.** Every coding agent's Fleet card and Code pane show a short outcome line: files changed, test results when a test run is linked, and whether the work is ready to merge, would conflict or has uncommitted changes. Anything KalCode hasn't seen says so instead of guessing, so a finished agent never reads as merged or shipped.
- **Spot agents editing the same files before you merge.** When coding agents work in their own worktrees in one project, their Fleet cards show "Overlaps with" the other agent when both changed the same files. The tooltip lists the files, and clicking it opens the other agent's terminal.
- **Project memory in Code.** A new Memory button in the Code header shows the active project's notes, pinned ones first, with an instant filter and notes that need review marked. Open Unified Memory from there to edit, pin or remove notes, and see what your agents receive.
- **Gemini CLI sign-in without security warnings.** Gemini CLI signed in through KalCode no longer prints "Security Warning" lines about its system settings.
- **A lighter Activity view, and Reduced motion that works.** The pulsing dot on working agent cards no longer repaints every card on every frame, so an idle Activity view uses far less CPU. The app's Reduced motion setting now stops that pulse too.
- **Less background work.** KalCode backs off its scan of related processes while nothing is changing, so an idle workspace uses less CPU. The Browser pane updates as soon as a page navigates, loads or changes its title, and checks less often while nothing changes. Status readings refresh at most twice a second during bursts of activity and wait while the KalCode window is hidden.
- **An accurate plan list, with provider accounts on every plan.** Your KalCode account settings now list shipped features as available, including Live Browser on every plan, terminal basics, favorites, native provider tools, and Agent Hand Off on MAX. Keeping your provider accounts in KalCode is now included on every plan, including Free.

- macOS 14 or later, Apple silicon.
