## Verification

### Installer install/uninstall test

Installer install test for this exact build (`0f259a8f…`): not run. The owner's real KalCode
install was put on the build machine after this build, and the test must never run next to a
real install (it would overwrite or remove it).

The same test **passed** on the build of the previous commit,
`cbe119bc69ef7c5bd5ee219c363db43a84e9d8b7` (installer SHA-256
`832fbb52ea3450316ccc0bd1def5713858d43401799de16a669e71ebf89330a9`, 3,836,675 bytes). The two
commits differ only in `tooling/release/*` and `docs/RELEASING.md`; the app sources are
identical. The Tauri/NSIS output is not byte-reproducible between builds, which is why the
SHA-256 differs. 41 checks, all passing:

- Staged file matched its build record (size, SHA-256); signature status recorded as `NotSigned`.
- Safety preflight: no existing KalCode install, shortcut or running `kalcode.exe`.
- Pass 1, `/S /NS /D=<temp>\KalCode`: exit 0; installed files exactly `kalcode.exe`
  (7,734,272 bytes) and `uninstall.exe` (79,119 bytes); `kalcode.exe` version resource
  ProductName KalCode, ProductVersion/FileVersion 0.1.0, CompanyName KalCode; the installed
  `kalcode.exe` equals `target/release/kalcode.exe` except the 3-byte bundle-type marker Tauri
  sets to `NSS`; uninstall entry in
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\KalCode` (DisplayName KalCode,
  DisplayVersion 0.1.0, Publisher KalCode, InstallLocation and UninstallString in the temp
  folder, EstimatedSize 7630 KB, NoModify/NoRepair); no autostart value; no shortcuts.
  Silent uninstall removed the files, the folder and the uninstall entry.
- Pass 2, `/S /D=<temp>\KalCode`: the same, plus `KalCode.lnk` created in the user's Start Menu
  `Programs` folder and on the desktop, and both removed by the silent uninstall.
- After both passes: no uninstall entry, shortcuts or `HKCU\Software\KalCode` key left (the
  uninstaller keeps `HKCU\Software\KalCode\KalCode` by design; the test removed the copy it had
  created). `%APPDATA%\com.kalcode.desktop` and `%LOCALAPPDATA%\com.kalcode.desktop` unchanged
  (existence and folder timestamp; never opened). KalCode was never launched.

### Real-app end-to-end tests (same commit)

## Windows SmartScreen

The installer is not code-signed. When you run it, Windows SmartScreen may show "Windows
protected your PC" because the publisher is unknown and the file is new. If you downloaded it from
kalcoded.com and the SHA-256 matches the value above, choose **More info → Run anyway**.

## Known limitations

- Unsigned installer and app (see above). No in-app updates yet: install a newer version over the
  old one; settings and history in `%APPDATA%\com.kalcode.desktop` are kept.
- Windows x64 only. macOS and Linux builds do not exist yet.
