# KalCode 0.1.9 (build 1950)

Source commit: `1f7b3288182b2f5fa274161a1ac2a13b76c7e8cf`.

## New in this build

- **Credential folders always ask first.** A command that names a credential folder itself, such as `~/.ssh`, `~/.aws`, `~/.docker` or `~/.kube` (for example searching, copying or archiving the whole folder), now asks for permission even in Bypass mode, just like reading a file inside it. A path in your project that is really a link to a credential folder or file asks too, whatever its name.
- **Usage recovers sooner after a failed reading.** When a live Claude usage reading failed, for example while offline or rate limited, Accounts & Usage kept saying the usage couldn't be read for up to 10 minutes, even after a running agent had reported a newer reading. That newer reading now shows right away.
- **Stopping a terminal is no longer a failure.** When you stop a terminal it now simply shows as ended, without the red "failed, exit code 1" badge, the red tab dot or an exit code note in KalTidy.
- **Restart never opens in the wrong folder.** If the folder a terminal was started in has since been deleted, Restart now shows an error and leaves the tab ended, instead of quietly starting the shell in your home folder.
- **Your saved layouts and pins are kept.** If the saved pane layout can't be loaded, KalCode shows the default layout without saving over yours and keeps retrying, then shows your saved layout once it loads. Pins and group moves are no longer lost after 500 saved entries, and removing a workspace now also removes its saved layout.
- **Finished Claude agents no longer show Needs You.** About a minute after a Claude agent finished its turn, it was flagged as waiting for your input and handoffs to it were held. It now stays idle and ready for handoffs. Real questions and permission prompts still show Needs You.
- **Cursor starts even when its model list can't be read.** If Cursor's model list fails to load, for example on a network hiccup, the pane now starts with the model you selected and lets Cursor check it. A model that Cursor's list leaves out is still refused with a clear message.
- **Provider panes stay responsive during handoffs.** Resizing, attaching and detaching provider panes no longer waits, for up to 5 seconds, while a handoff or a KalVoice command is being delivered to an agent.
- **Live Browser addresses and history fixes.** Back and Forward no longer leave the Live Browser stuck on Loading when there is no page to go to or the page stays in place, as in single-page apps. Addresses with a port, such as `example.com:8080` or `dev.localhost:5173`, now open instead of being rejected, and local and private network addresses such as `0.0.0.0:3000` or `192.168.1.5:5173` open over http so plain-HTTP dev servers load. A browser pane on an address with a stray `%`, such as `localhost:3000/100%`, no longer stops the layout from saving.
- **Fixed: the Environment chip saying Production.** A few seconds after opening a folder that was never deployed, the top-bar Environment chip switched from Local to "Production, Unknown". It now stays on Local until an environment has a recorded deployment.

## Platforms

- Windows 10 version 1809 or later, x64.
- macOS 14 or later, Apple silicon.
