# KalCode 0.1.9 (build 1908)

Source commit: `4527b1db90a8aa6d57ae5d508a17ca426f4d436b`.

## New in this build

- **A new space look, scaled to each page.** Behind the app's panels there is now a faint far star field and a soft nebula. How much shows depends on the page: Settings and Unified Memory stay quietest, work pages such as Code and Operations are in between, and Activity and KalVoice show the most. The background never animates, the light theme keeps only a faint wash, and high contrast removes it and every glow.
- **The focused pane is easy to spot.** When a Code pane takes focus, a short blue light runs once around its edge and settles into a lit outline. Panes you are not focused on show their state as a thin edge: amber when waiting or paused, red when failed. Reduced motion skips the sweep, and terminal text stays sharp.
- **A new start screen in Code and a sharper Live Browser.** With no project open, Code shows a new launch screen with the same "Open a project folder" button. The Live Browser toolbar now lights up when its pane is focused and the browser opens with a short transition, which Reduced motion turns off.
- **Activity cards show state at a glance.** Agent cards carry a colored top edge for their state, lift on hover, get a blue edge when focused and a steady amber glow when they need you. The Needs You line gets an amber edge while something is blocked, and "No agents yet" is now a centered welcome with a rocket.
- **Operations reads like live telemetry.** Summary tiles show a status light while their count is live, run rows have a colored status rail, and the run detail header takes the run's status color. Timeline steps are colored by what they recorded, running services are highlighted, and environments show a health band only when they are verified healthy or failed.
- **Clearer usage meters.** The usage meter in the accounts table is wider and easier to read, while "usage unavailable" stays compact. Meters in the Account Hub glow softly, and the usage center gets a lit top edge.
- **Frosted menus, tooltips, toasts and command palette.** Menus, context menus, tooltips, toasts, the command palette and the update notice now float as frosted glass with a lit top edge. The highlighted menu item is marked with a blue edge, and each toast has a colored bar that shows what kind of message it is. The sign-in, startup and startup error screens sit on the starry background with solid cards behind all text.
- **Jump to any Settings section.** Settings now has a row of section buttons that stays at the top as you scroll. Clicking one scrolls to that section and moves keyboard focus to it.
- **KalVoice shows where a command landed.** After a voice command that opens a page, an agent, a terminal or a thread, changes panes, shows approvals or focuses something in Operations, a short streak travels from the KalVoice orb to the result, and the result lights up for about a second. This is visual only and does not change what the command does. With Reduced motion there is no streak, but the result still lights up.
- **KalVoice is calmer when idle and clearer when listening.** The idle orb no longer spins or pulses and the idle waveform stays still, so a waiting KalVoice does no animation work. While you hold to talk, the widget lights up right away and the glow around the orb follows your real microphone level, and processing shows a green edge. The example list now suggests "Start three Codex agents".
- **Fixed: crowded "In development" pages.** The intro panel on pages still in development now sizes to the space it actually has, so its details no longer get squeezed or overlap when side panels are open. The artwork hides first when space runs out.

- Windows 10 version 1809 or later, x64.
- macOS 14 or later, Apple silicon.
