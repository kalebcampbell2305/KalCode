# KalCode 0.1.9 (build 1467)

Source commit: `c51866805b64cf59ff4971a731ed373826e43976`.

## New in this build

- Connect workspace tools through the new Integration Hub: custom APIs, trusted remote MCP servers, and supported private systems through OpenAI Secure MCP Tunnel.
- Inspect real discovered capabilities, connection health and session access in one place. External tool access stays scoped to the workspace and selected coding session or workflow.
- Use the same tool authority from Code and KalVoice. OpenAI Responses requests use an explicitly configured personal API key; supported models discover tools as needed.
- Sensitive external actions pause for an exact, one-use approval. Credentials remain in operating-system storage, and external results do not automatically become permanent memory.

## Platforms

- Windows 10 version 1809 or later, x64.
- macOS 14 or later, Apple silicon.
