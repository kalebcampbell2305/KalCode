# KalCode 0.1.7

This release fixes in-app updates on Windows and several update and KalVoice problems found in 0.1.6.

## Upgrading

- **Windows, from 0.1.6:** KalCode 0.1.6 can't install updates on Windows: its Update and Restore previous version buttons can't start the installer. Download the 0.1.7 installer from kalcoded.com/download and run it once over your current copy; your workspaces, threads, settings and sign-ins are kept. From 0.1.7 on, KalCode installs later updates from inside the app.
- **macOS, from 0.1.6:** update from inside the app with Restart to update or Settings > Updates.
- **0.1.2 is not a release.** That version number is used only for a private test build.

## Changes

- **Windows in-app updates:** Update and Restore previous version now start the installer. In 0.1.6 they couldn't start the installer because KalCode still held it open for writing. If the installer ever fails to start, Settings > Updates now names that failure instead of reporting that the install did not advance.
- **One update at a time:** clicking Update or Restore previous version while an install is already running is refused and no longer disturbs the install in progress.
- **Sign-out during an update:** an update or quit now waits for a sign-out that is still clearing your credentials, so the sign-out always takes effect.
- **Quitting during update preparation:** quitting while an update is being prepared cancels and cleans up that preparation. On macOS this no longer leaves a hidden temporary copy and disk image behind.
- **KalVoice orb:** KalVoice stops listening when you let go of the orb, even after a quick tap, when KalCode loses focus, when you cancel, or after two minutes. In 0.1.6 it could keep listening until you pressed Esc.
- **Fn push-to-talk on macOS:** with KalCode as the active app, hold Fn on a Mac keyboard to talk and let go to stop. A quick tap of Fn keeps its usual action, and using Fn with another key (such as Fn+Up) never sends dictation. F8, or the key you configured, keeps working as the fallback push-to-talk key. Most Windows keyboards don't report Fn to apps, so use F8 there.

## Known issues

- Settings > Permissions says every mode is available on every plan. Stable 0.1.7 offers Plan, Approve and Auto on every plan; Bypass and Custom are planned.
- The app binaries contain file paths from the build machine, including the build account's user folder name. They contain no credentials, tokens or email addresses.
- Gemini CLI is still unavailable in KalCode, as described in the 0.1.6 notes. Claude Code and Codex are unaffected.
- If you start an update or Restore previous version while a provider sign-in or a file or folder picker is still open, the update stops and KalCode says to close sign-in or file dialogs and try again.

## Platforms

| Platform | Package and requirements |
| --- | --- |
| Windows 10 (1809) or later, x64 | Signed per-user NSIS installer. |
| macOS 14 or later, Apple silicon arm64 | Developer ID-signed and notarized DMG with a stapled notarization ticket. Use `~/Applications/KalCode.app` for standard-user in-app updates and rollback. The DMG's Applications shortcut targets system `/Applications`, where later replacement requires administrator authority. |
| Intel Mac, universal Mac, Linux | No release artifact. |

Provider usage remains billed by your provider.
