# Navigation system

KalCode now keeps a chronological history of surfaces, workspaces, coding panes, Threads, provider accounts, Settings sections and Runs. Back and Forward select existing sessions; visiting a new destination after Back starts a new history branch. Closed panes and removed workspaces are skipped.

The navigation bar includes breadcrumbs and recent visits. Browser is reachable from the sidebar and command palette. Visited Code workspaces retain their mounted terminals and Browser panes, including when another workspace or surface is in front.

The universal quick switcher searches workspaces, Threads, coding agents, terminals, files, providers, accounts, Settings, commands and release information. A local index serves results immediately while metadata refreshes in the background. Results include contextual details and prefer exact matches, the current workspace and recent use. File indexing runs incrementally, skips ignored/build directories and caches visited workspaces.
