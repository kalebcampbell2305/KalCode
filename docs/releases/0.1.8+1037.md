# KalCode 0.1.8 (build 1037)

This build of KalCode 0.1.8 adds the Command Deck, Agent Fleet, the Provider Dock, plan limits with monthly or yearly plans, and KalVoice control of your workspace and agents, and makes Code faster. From this build on, every update, including a new version, downloads in the background and installs when you close KalCode. It updates KalCode's data to save each thread's reasoning effort, after first making its usual backup, so once it has updated your data Restore previous version can't go back to earlier builds.

## Upgrading

- **From an earlier build of 0.1.8:** this build downloads and is verified in the background, then installs without a prompt when you close KalCode, so the next launch runs it. Your workspaces, threads, settings and sign-ins are kept. You can also install the download from kalcoded.com/download over your current copy.
- **From 0.1.7:** KalCode offers 0.1.8 as an update. Install it with Restart to update or Settings > Updates, or install the download from kalcoded.com/download over your current copy. Your data is kept.
- **Windows, from 0.1.6:** KalCode 0.1.6 can't install updates on Windows. Download the installer from kalcoded.com/download and run it once over your current copy; your data is kept.
- **macOS, from 0.1.6:** update from inside the app with Restart to update or Settings > Updates.
- **Later updates:** from this build on, every update, including a new version, downloads and is verified in the background and installs when you close KalCode. It never installs while KalCode restarts or Windows signs out or shuts down. On macOS KalCode checks that the new build starts before keeping it.
- **Version numbers:** KalCode shows version 0.1.8. Settings > Updates and other detailed views add the build number, for example "0.1.8 build 1037". Version 0.1.2 with a build number is only for a private test build and is never offered as an update.
- **Going back:** KalCode offers Restore previous version only for a build that can open your data. A restore that would reach an older build stops with "The previous version can't open data saved by this version, so it can't be restored. Your data has not been changed."

## Changes in this build

- **Command Deck:** the window is organized around what is working, what needs you and what is shipping. The top bar shows your workspace, its Git branch and changes, the environment, the permission mode new threads start in, search and commands (Ctrl+K or Cmd+K) and live counts of working and waiting agents. Projects sit in the sidebar, a rail on the right lists every running agent, and a strip along the bottom shows builds, tests, provider health and what is shipping.
- **Agent Fleet:** the Dashboard shows each agent as a live card with its call sign, account, workspace, branch, current action, changed files and whether it needs you. A new thread in a Git workspace runs in its own worktree and branch (on by default), so parallel agents never change the same folder. Ready to merge appears only when the agent stopped without failing, its work is committed and Git reports no conflicts; Commit changes commits leftover changes on its branch. Archiving removes a clean worktree folder and keeps the branch.
- **Provider Dock:** every connected account appears in the status strip with its sign-in health and running threads. Move the open thread to another compatible account from its menu, or drag a thread onto it and confirm. KalCode never switches accounts on its own.
- **KalVoice controls your workspace:** ask KalVoice to open or focus a thread, terminal, agent, Operations run or service, then follow up with "open it" or "that one". It can start Claude Code or Codex agents with your signed-in accounts, model and effort, and send a prompt to an agent. When several things match, it asks which one. It can also say when an agent finishes, fails or needs you.
- **KalVoice sign-in reminders** follow provider health, so signing out of a provider updates them right away. Push to talk can be cancelled while it is still starting: let go of the key or press Esc.
- **Faster Code:** switching back to Code keeps your terminals and their history in place instead of reloading them, and switching terminal tabs no longer rebuilds the terminal. New terminal tabs appear as soon as the shell starts, closing a tab is immediate, the Dashboard opens without reloading, and Operations' Refresh no longer locks up during background updates.
- **Reasoning effort:** a thread keeps the reasoning effort chosen for Claude Code or Codex, including after a restart.
- **Plan limits count across KalCode:** open terminals Free 4, Pro 12, MAX 18; workspaces Free 2, Pro 10; provider accounts Free 2, Pro 6, MAX 8; parallel agents Free 1, Pro 4, MAX 10. Higher plans have no KalCode limit. Reaching a limit never closes anything: KalCode only declines to open one more and says how many the next plan allows. If your plan can't be verified, the Free limits apply.
- **KalVoice Requests a month:** Free 25, Pro 150, MAX 500, MAX 2X 1,000. Each KalVoice command KalCode carries out counts once; dictation and voice into terminals never count.
- **Monthly or yearly:** onboarding offers Pro, MAX and MAX 2X monthly or yearly ($100, $250 or $500 a year). Free stays $0.
- **Free run history:** on Free, Operations > Runs lists your 10 most recent finished runs; running work and the open run always stay listed.
- **Empty Code pane:** its hint now says closing a pane ends what runs in it.

## Earlier 0.1.8 changes

- **Operations:** follow your project's work from the queue to its result. KalCode asks before anything runs, and a restart never reruns work on its own.
- **KalTidy** (build 944): the broom button in the Code toolbar, the Command Palette or KalVoice ("close all idle terminals") stops idle terminals. Agents, services, Operations work and the focused terminal are never stopped by default.
- **Account Hub** (build 944): your name and plan at the foot of the sidebar open Account & plan, Usage, Billing, providers, KalVoice, Settings and Sign out.
- **Providers > Accounts** (build 944): a compact list grouped by provider with health, sign-in status and quick actions.
- **Closing a terminal or agent ends it** (build 923), and **F8 push to talk** works again within about half a second of KalCode getting focus back on Windows (build 923).
- **Fixes:** Windows no longer freezes on focus changes, and KalVoice no longer closes KalCode when memory is low.
- **Look:** a focused terminal gets one quick blue trace, amber means waiting for you, and the mascot is the app icon on Windows and macOS.

## Known issues

- Settings > Permissions says every mode is available on every plan. Stable 0.1.8 offers Plan, Approve and Auto on every plan; Bypass and Custom are planned.
- Codex agents can't commit inside their own worktree, because their sandbox can't write the repository's Git data. Use Commit changes on the agent's card.
- Gemini CLI is still unavailable in KalCode, as described in the 0.1.6 notes. Claude Code and Codex are unaffected.
- If you start an update or Restore previous version while a provider sign-in or a file or folder picker is still open, the update stops and KalCode says to close sign-in or file dialogs and try again.
- KalVoice intelligence (assistant) responses can be delayed after you finish speaking.
- After updating, KalVoice's on-device intelligence can take a few minutes to become ready while KalCode cleans up the previous version's worker; it then starts on its own.
- The app binaries contain file paths from the build machine, including the build account's user folder name. They contain no credentials, tokens or email addresses.
