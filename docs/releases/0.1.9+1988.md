# KalCode 0.1.9 (build 1988)

Source commit: `cc816975a3e3f8c5441aa2a53270a9a22e2489f8`.

## New in this build

- **The agents rail stays put when you launch an agent.** A new agent shows "Starting" for about a second, and the rail used to pop open for it and then fold back, leaving an empty panel that squeezed the workspace. The rail now opens on its own only when an agent is working, waiting on something, or needs you. Pinning and collapsing it work as before.
- **Code toolbar buttons are never cut off.** In narrower windows, especially with the agents rail open, the Tidy and Layout buttons could be clipped and the workspace name squeezed. The Tools, Memory, Terminal, Tidy and Layout labels now fold into icons sooner, and the workspace name shortens before any button would be clipped.
- **Agent states match everywhere.** KalTidy's "Clear failed" and a card's X now clear an agent that is idle after a failed last turn, which the Fleet already counts as failed. The "threads can be resumed" notification now opens the Fleet on Done, where the recovered threads are listed, instead of Idle. The project page and the rail and home counts now agree with the Fleet: a failed thread no longer counts as waiting for you.

## Platforms

- Windows 10 version 1809 or later, x64.
- macOS 14 or later, Apple silicon.
