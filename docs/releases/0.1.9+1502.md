# KalCode 0.1.9 (build 1502)

Source commit: `eb8db32912f84acceb347bbb92bb9d5d447c553e`.

## New in this build

- Cursor joins Claude Code, Codex and Gemini CLI as a native coding provider in Code. Launch independent Cursor Agent terminals in the current workspace, find them in Agent Fleet, and use the shared KalVoice and orchestration tools.
- Cursor model choices come from the authenticated Cursor runtime, preserving exact model identifiers. KalCode does not invent unavailable models or separate effort settings.
- The supported Cursor integration reuses one persistent native sign-in across independent coding terminals. Usage is shown as unavailable when Cursor does not expose reliable account usage.
- Saved project context follows Cursor agents through KalCode Unified Memory. Native startup and task context do not create extra model turns, and saved knowledge remains shared with other providers.
