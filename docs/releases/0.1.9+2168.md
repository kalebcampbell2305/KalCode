# KalCode 0.1.9 (build 2168)

Source commit: `29c19a7873f355e6f108999f73016fc30fda6227`.

## New in this build

- **KalCode can continue where you left off.** After a restart, KalCode brings back your saved panes, their names, layout and focus, your Browser pages and your unsent drafts, and resumes the coding agents that can be resumed while you start working. Choose how in Settings, under "Continue where I left off": restore your desk automatically, or only when you click "Continue where I left off". Queued tasks wait until you click "Resume queued task", finished commands and agents you closed stay ended, and New Agent always starts fresh.
- **Closing a pane now stops its agent.** "Close active work?" now offers Stop and Close or Cancel, and the agent you close stays closed after a restart instead of coming back.
- **You can no longer get stuck on "Confirming plan".** If you closed checkout without paying, the screen now offers "Choose a different plan" and "Sign out", and the plan choice screen offers "Sign out" too. If sending the email sign-in link fails, the form keeps the address you typed. If you haven't set an account name, the Account Hub shows the first part of your email address, as Settings says it will.
- **Usage readings are more accurate.** An account with less than 1% left now shows "<1% left" with a sliver of bar instead of "0% left". A weekly limit for one model, such as Fable, now warns only when you launch that model. Accounts whose usage can't be read now say "Usage unavailable".
- **Agent Fleet, the agents rail and Needs You agree.** A Fleet card no longer says "Ready to merge" for an agent that failed or needs you. Focus, Open Browser beside and Duplicate agent in an agent's right-click menu now always open the agent in Code, never in Threads. A cleared agent that you restore from Archived shows up in the agents rail again, with its X.
- **Keyboard Back and Forward work.** Alt+Left and Alt+Right on Windows, and Cmd+[ and Cmd+] on macOS, now move through your history instead of cancelling themselves. On Windows, Alt+Left or Alt+Right on a focused favorite now only reorders it. Picking a coding agent in the command palette now always opens it in Code.
- **Answered permission requests clear from Needs You.** A permission notice you had already answered could stay unread in Needs You, with its badge, until you restarted. It now clears as soon as the agent stops waiting. Doctor and Utility Dock approval requests that nobody answered in time now show as "Expired: its approval window passed" instead of staying pending until a restart. When an agent asks for the same approval again, screen readers announce it again instead of staying silent.
- **Code panes, shortcuts and New agent behave.** Agent panes now use Settings > Text size like other terminals, and an agent you resume comes back in the current theme. Ctrl+Shift+E now leaves an agent terminal, as it does in other terminals. Holding `` Ctrl+Shift+` `` opens one terminal instead of one per key repeat. Keyboard focus moves into the New agent dialog even while accounts are still loading. In a hand-off, Return findings waits until a send in progress finishes. Run Tests now opens the Tests tab in the workspace you are looking at, not in one hidden in the background. On a narrow canvas, the Stack opens with keyboard focus inside it, Esc closes it, and focus goes back to the rail. "New group..." is offered only while the stack is grouped.
- **Integrations are more reliable.** A call that finished is no longer reported as failed, and offered again, when the integration's settings changed while it ran. Connecting an integration that signs in with GitHub-style OAuth now works, and KalVoice picks up a reconnected integration right away.
- **Doctor and Utility Dock are more dependable.** In Doctor, Ignore now works on findings that don't belong to a workspace even while one is open, and cancelling a run still shows the findings from checks that finished. The database check now stops at its time limit, and macOS and Linux are no longer shown as "Mac OS (build 0)".
- **Screen readers no longer stumble over decorative layers.** The remaining decorative edges and rails are hidden from assistive technology, so screen readers read only the content.
- **Run now starts right away.** Clicking Run now on a queued agent task is no longer held back, and then failed, because your computer's CPU is busy.

## Platforms

- Windows 10 version 1809 or later, x64.
- macOS 14 or later, Apple silicon.
