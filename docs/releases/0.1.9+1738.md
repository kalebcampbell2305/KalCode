# KalCode 0.1.9 (build 1738)

Source commit: `ce685df525e125313b67bb3300974900a73d1315`.

## New in this build

- **One agent state everywhere.** Every coding agent, on any provider, now shows the same clear state in the Dashboard, the agent rail, Code and its panes, and KalVoice: starting, working, waiting, needs you, ready, done or failed.
- **Faster terminals.** Terminal output is batched, writes to terminals and panes happen off the main thread, and finding running processes and ports is faster, so busy agents and long builds stay smooth.
- **Account suggestions, never silent switches.** When an account is limited, KalCode suggests another account you have connected; it only switches when you choose to.
- **Truthful account usage and more reliable launches.** Account usage shows what the provider reports, coding agents launch more reliably, and a requested sign-in is kept even if the screen redraws.
- **Agents keep their names, and Codex can use up to ten sub-agents.** Task names persist across restarts.
- **Workspace favorites and global pins.** Pin the workspaces and destinations you use most and reach them from anywhere.
- **Codex follows your rules.** Your own Codex rules files now apply inside KalCode.
- **Your agents come first.** Scheduled background sessions now wait while your computer is busy, so the coding agents you start are never held back.

## Platforms

- Windows 10 version 1809 or later, x64.
- macOS 14 or later, Apple silicon.
