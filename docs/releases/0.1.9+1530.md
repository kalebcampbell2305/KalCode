# KalCode 0.1.9 (build 1530)

Source commit: `68495327b2e2fbce6646f015180cede94940b965`.

## New in this build

- **Terminal Organization in Code.** Busy workspaces stay scannable in seconds. Terminals are named by what they run (Frontend, Backend, Tests, Release) and agents by their call sign and name ("Claude A - Dashboard"); names you set yourself are always kept.
- **Status you can trust.** Every terminal and agent shows one of Starting, Ready, Working, Testing, Waiting, Failed, Done or Idle, read from real process, session and run state. Done and Failed come only from an exit code or the agent's own status, and KalCode shows no badge rather than guess.
- **Terminal Stack.** A side stack groups the workspace by purpose (collapsible, rearrangeable, or one list). Waiting work is marked, finished work folds away unless pinned or focused, and nothing is closed. It appears once a workspace is busy and remembers your choices per workspace.
- **Quick bar and What's Happening.** + Agent, + Terminal, Browser, Widgets, Run Tests, KalTidy and Focus sit in one compact row, with small working and needs-you counters. The status bar now reads like "2 agents working - 1 needs you - tests passing - localhost:3000 - main clean", and each part opens what it describes. Run Tests re-runs your latest test task and asks first.
- **Narrow windows keep the workspace name.** The Code header folds its labels instead of squeezing out the workspace title.
- External integrations are listed as available on every plan, using your own credentials.

## Platforms

- Windows 10 version 1809 or later, x64.
- macOS 14 or later, Apple silicon.
