# KalCode 0.1.9 (build 2184)

Source commit: `123dd44eac986bbd684b48342e8b40e3925403c0`.

## New in this build

- **Mac updates no longer need Apple developer tools.** KalCode now checks that a macOS update matches your Mac's chip by itself, so updates install even on Macs without Xcode command line tools.
- **Safer updates.** KalCode now refuses an update whose signature was issued for a different update channel or platform.

## Platforms

- Windows 10 version 1809 or later, x64.
- macOS 14 or later, Apple silicon.
