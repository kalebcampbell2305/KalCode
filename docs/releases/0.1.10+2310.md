# KalCode 0.1.10 (build 2310)

Source commit: `23ed9d14a568c415103c73b500ed25f3db5fe83e`.

## New in this build

- **Agent File Ownership.** When several coding agents work in one project, KalCode shows which agent is working on which files and warns early when they collide: the same files, changes Git says will conflict, or one agent inside another's area. Badges appear on agent cards, Code panes and file views; Allow both keeps an intentional overlap, and ownership moves with a handoff (#372).
- **Codex updates without breaking.** KalCode picks up compatible Codex CLI versions automatically and falls back to the last version that worked if an update is incompatible (#373).
- **Exact agent identity.** Every agent shows and launches with its exact account, model and reasoning effort, wherever you see it (#377).
- **Agent Handoff Chains** are now listed as available on MAX plans and above (#394).

## Platforms

- Windows 10 version 1809 or later, x64.
- macOS 14 or later, Apple silicon.
