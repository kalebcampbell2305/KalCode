# KalCode 0.1.9 (build 1873)

Source commit: `9b115298f73d39814547e9bb1867dda2c7ad5c67`.

## New in this build

- **A lighter KalCode with many agents, and Reduced motion that works everywhere.** Times such as "2 min ago" now update from one shared clock and only redraw when their text changes, so with ten agents the Code tab redraws about a third as often. Worktree cards no longer redraw when nothing changed, and glows, loading bars and placeholders animate without repainting the page. The app's Reduced motion setting now stops every repeating animation, including KalVoice's, and Full motion overrides the system setting.
- **Long Activity titles stay readable.** A long event title in the Activity widget now ends in an ellipsis instead of running into its time, and hovering shows the full title.

## Platforms

- Windows 10 version 1809 or later, x64.
- macOS 14 or later, Apple silicon.
