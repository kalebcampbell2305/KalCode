# Z7-W0 — Design system: the approved premium direction in the desktop app

Branch `z7/design-system` (from main `a8256b7`), worktree `.worktrees/z7-design`. Scope: the
foundation the other Z7 writers build on — tokens, shared components, and a restyle of the existing
desktop surfaces **without** layout rewrites (W1 panes, W2 rail/home, W3 Dashboard/notifications
come later). No Rust changes. No push or merge.

Owner requirement (ADVANCED §16): the app joins the approved visual direction — dark, polished,
cinematic, technical, high-end — denser than the website, with nothing bland, generic, empty or
unfinished, and it shares tokens and components with the website.

## Critique against the concepts, and what is left

- **KPI tiles have no trend lines.** The concepts show sparklines. The app has no time-series data
  yet, and KalCode never fabricates data. `Sparkline` is ready for W3.
- **The KalVoice widget overlaps page headers** at the top centre (on Code at 1440 it covers the end
  of the path pill). This predates W0 (it is in `before/`). It needs a reserved slot in the shell,
  so it goes to W1/W2.
- **Ultrawide composition** (3440) fills the window, but the columns are wide rather than
  recomposed. Adding panes and widgets at that width is W1/W3's job.
- The website stage keeps its own aliases (`--kc-attention` → idle grey, `--kc-paused` → amber) and
  was not re-tinted. It can adopt `--status-*` when the website is next touched.

## APIs the later Z7 writers must use

- **Surfaces:** `Panel` (`title`, `eyebrow`, `icon`, `count`/`countTone`, `actions`,
  `description`, `footer`, `tone` default/lit/flush, `padding`, `id`) and `Surface` (`level`,
  `lit`, `interactive`, `sunken`). Light one thing at a time.
- **Status:** `StatusChip status={displayStatusOf(s).status}` (+ `qualifier`,
  `variant` chip/inline/dot, `size`), or `--status-<tone>{,-soft,-text,-line}` in CSS. Never
  `--color-waiting` for status.
- **Provider identity:** `ProviderMark provider={id} detail={model} tile size`, or `ProviderGlyph`
  on its own; `providerIdentity(id)`.
- **KPIs:** `StatGroup` + `Stat` (`label`, `value`, `icon`, `tone`, `hint`, `trend`,
  `onSelect`/`selected` for filter chips) + `Sparkline` (fed only from real data).
- **Lists:** `Table` (`dense`, `stickyHeader`, `framed`, `caption`) and `RowList`/`RowItem`
  (`selected`, `interactive`).
- **Tabs:** `Tabs`/`TabsList variant="line"|"pill"`/`TabsTrigger`/`TabsContent`.
- **States:** `EmptyState` (framed by default; `framed={false}` inside a Panel; `artStyle`),
  `ErrorState` (`code`, `framed`), `Skeleton`.
- **Controls:** `Button` (primary/secondary/ghost/danger), `IconButton`, `Badge` (incl. `paused`),
  `SegmentedControl`, `Field`/`TextInput`/`TextArea`/`Select`, `DropdownMenu*`, `Tooltip`, `Kbd`.
- **Tokens:** type roles `--type-*`, `--font-label`, `--tracking-label`; `--color-surface-1..3`,
  `--panel-sheen`, `--color-border-lit(-soft)`, `--shadow-panel/-lit/-xl/-well`,
  `--app-backdrop`; `--panel-px/-py/-header-h/-gap`, `--row-h-dense`; `--ease-emphasized`,
  `--dur-status`, `--dur-pulse`; terminal `--term-*` and `--provider-*` from `terminal.css`
  (imported in `apps/desktop/src/main.tsx`).
