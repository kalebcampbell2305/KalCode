## APIs for the other writers

- **Show content in panes (W3 Dashboard, W2 surfaces):** `registerPaneContent("dashboard", { describe, render })`
  from `apps/desktop/src/shell/panes` (`describe(content) → TabInfo { title, glyph, tone?, stateLabel?, statusText? }`,
  `render(content, { paneId, tabId, focused, focusRequest }) → ReactNode`). Call it at module load of the
  Dashboard's pane view; the canvas re-renders when a registration arrives. Widgets:
  `registerPaneWidget(widgetId, …)`; widget ids `^[a-z0-9][a-z0-9_.-]{0,63}$`. `registeredWidgets()` feeds the
  "Add" menus. Until W3 registers, the Dashboard pane shows an honest "Open Dashboard" notice.
- **Card → pane focus, notifications, search results:** `useOpenInPane()(content, { workspaceId })` switches to
  the content's workspace, goes to Code and opens and focuses it once that workspace's canvas is up. A thread that
  isn't a provider pane opens in Threads. Lower level: `dispatchPaneCommand(command, { queue, scope })`.
- **Layout store for PC/BP:** `kalcode_workspace_ui::store::{get_layout, save_layout, list_presets, save_preset}`
  (Rust) and the five `layout_*` IPC commands; the stored value is the contract `PaneLayout`.
- **Shell slots:** `useShellSlots()` (`shell/ShellSlots.tsx`) for anything that must float without covering
  headers.
