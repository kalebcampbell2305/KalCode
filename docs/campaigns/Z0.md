# Campaign Z0 — Foundation

Goal: a professional, tested foundation on which every later campaign builds.

## Acceptance matrix

Each criterion is marked PASS / FAIL / PARTIAL with evidence once verified. Criteria are not
marked PASS from source inspection alone when they can be executed.

### Repository & tooling
- [ ] Z0-01 Monorepo builds from a clean checkout (`pnpm install`, `cargo build`).
- [ ] Z0-02 Formatting, lint (Biome, Clippy `-D warnings`) and typecheck pass.
- [ ] Z0-03 CI workflow runs format, lint, typecheck, tests, builds on Windows/macOS/Linux.
- [ ] Z0-04 Branding check passes: no previous product name, no competitor references, no private-system material.

### Native runtime
- [ ] Z0-05 SQLite database opens with WAL + foreign keys; migrations apply on fresh install.
- [ ] Z0-06 Upgrade path tested: existing database with data migrates, backup is written, data intact.
- [ ] Z0-07 Newer-than-app schema and edited-migration checksum are refused with typed errors.
- [ ] Z0-08 Event store: append assigns monotonic `seq`, persisted before publish, pagination correct.
- [ ] Z0-09 Unknown event types decode as `unrecognized` without failing.
- [ ] Z0-10 Settings: validated, persisted, emit `settings.changed`.
- [ ] Z0-11 Error taxonomy crosses IPC as `{category, code, message, retryable}`; internals not leaked.
- [ ] Z0-12 Structured JSON logs written with rotation; secrets redacted (tested).
- [ ] Z0-13 Secure store: OS keychain round-trip works on this machine; secret values never logged.
- [ ] Z0-14 IPC allow-list: only KalCode commands callable; CSP strict; no fs/shell plugins.

### Protocol
- [ ] Z0-15 TypeScript types generated from Rust; CI detects drift.
- [ ] Z0-16 Plans centralized (Free $0 / Pro $10 / MAX $25) with tests.
- [ ] Z0-17 Provider and permission contracts defined and documented.
