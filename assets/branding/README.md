# KalCode production brand assets

Generated by `python tooling/generate-brand-assets.py` from the owner's brand boards
(`packages/ui/src/brand/masters/kalcode-board.png`, `kalvoice-board.png` — byte-identical copies of
`KALCODE LOGO.png` and `KALVOICE LOGO.png`). Do not edit these files by hand; rerun the pipeline.

| File | What it is | Use |
| --- | --- | --- |
| `kalcode-icon-{1024,512,256,128,64,32}.png` | The KalCode symbol (terminal globe) isolated from the board, sphere body opaque, transparent background | Primary KalCode logo / app icon, any surface |
| `kalcode-symbol-{…}.png` | Same symbol, glow only (fully transparent body) | Dark surfaces and hero art |
| `kalvoice-icon-{…}.png` | The KalVoice orb isolated from the board, sphere body opaque | Primary KalVoice logo / icon, any surface |
| `kalvoice-orb-{…}.png` | Same orb, glow only | Dark surfaces and hero art |
| `*-source.png` | Full-resolution isolations (native board pixels, ~570–620 px) | Re-export at other sizes |
| `kalcode-wordmark.png`, `kalcode-tagline.png`, `kalvoice-wordmark.png`, `kalvoice-tagline.png` | Board lettering, white on transparent (luminance as alpha) | CSS masks tinted with `currentColor` |

Notes:

- Sizes below 96 px use a tighter crop around the sphere so the symbol stays legible.
- The boards are 1254 px square, so the 1024 exports are upscaled about 1.7× from the native
  isolation. The symbols are raster art (particle glow); they are not vectorized, because a
  tracing would not reproduce them faithfully.
- The small orbit labels on the KalCode board (IDE, AI, BUILD, CODE, TERMINAL, DEPLOY) are board
  annotations and are removed from the symbol. The ™ on the KalVoice board is not part of the
  extracted wordmark.
