# KalCode production brand assets

Generated by `python tooling/generate-brand-assets.py` from the owner's artwork
(`packages/ui/src/brand/masters/`: `kalcode-mascot.png`, a byte-identical copy of
`KalCode New Logo For Everything.png`, plus `kalcode-board.png` for the lettering and
`kalvoice-board.png`). Do not edit these files by hand; rerun the pipeline.

| File | What it is | Use |
| --- | --- | --- |
| `kalcode-icon-{1024,512,256,128,64,32}.png` | The mascot on its navy rounded tile (Apple 1024 grid, transparent margin). Head crop below 64 px. | Primary KalCode logo / app icon, any surface |
| `kalcode-mascot-light-{1024,512,256}.png`, `-source.png` | Full mascot, transparent, exactly as drawn (soft ground shadow kept) | Light backgrounds |
| `kalcode-mascot-dark-{1024,512,256}.png`, `-source.png` | Full mascot, transparent, soft blue rim light and glow, no shadow | Dark backgrounds |
| `social/kalcode-x-avatar-400.png` | Full-bleed square tile (X crops it to a circle) | X / Twitter profile image, other avatars |
| `social/kalcode-x-header-1500x500.png` | World plate, wordmark, tagline, mascot | X / Twitter header |
| `social/kalcode-og-1200x630.png` | World plate, mascot, wordmark, tagline | Link previews (same as the website `og.png`) |
| `kalvoice-icon-{...}.png` | The KalVoice orb isolated from the board, sphere body opaque | Primary KalVoice logo / icon, any surface |
| `kalvoice-orb-{...}.png` | Same orb, glow only | Dark surfaces and hero art |
| `kalvoice-*-source.png` | Full-resolution KalVoice isolations | Re-export at other sizes |
| `kalcode-wordmark.png`, `kalcode-tagline.png`, `kalvoice-wordmark.png`, `kalvoice-tagline.png` | Board lettering, white on transparent (luminance as alpha) | CSS masks tinted with `currentColor` |

Notes:

- The mascot master is 1254 px on white. The white ground is removed by flood-filling the light
  area connected to the border (the eyes, enclosed, stay white) and recovering alpha along its
  edges by un-mixing white, so the laptop's glow and antialiased edges carry no white fringe.
- The navy figure disappears on near-black; the dark variant's rim light and soft blue glow keep
  its silhouette. Nothing inside the figure is changed.
- The 1024 exports of the full mascot are a slight upscale of the ~1000 px native figure square.
  The mascot is raster art and is not vectorized.
- The KalCode board's terminal-globe symbol is retired; only its lettering is still derived.
