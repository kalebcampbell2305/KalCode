## LinkedIn

KalCode 0.1.9 is out.

KalCode is a workspace for AI software engineering. It brings Claude Code, Codex, your accounts, terminals, agents and engineering operations into one window. In 0.1.9 that window becomes a command deck:

- Command Deck: what's working, what needs you and what's shipping, at a glance
- Agent Fleet: parallel agents, each in its own worktree and branch, with a Ready to merge state backed by Git
- Provider Dock: every Claude Code and Codex account in the status strip, with one-drag thread moves

## Reddit / Discord (plain, no hype)

KalCode 0.1.9 is out for Windows 10+ (x64) and macOS 14+ (Apple silicon). Highlights:

- **Command Deck:** a new main shell with workspace, branch and environment up top, running agents on the right, and builds, tests, provider health and shipping along the bottom.
- **Agent Fleet:** each new agent works in its own git worktree and branch. Its card shows Ready to merge only when it stopped without failing, its work is committed, its branch is ahead and `git merge-tree` predicts no conflicts.
- **Provider Dock:** account chips in the status strip. Move a thread between same-provider accounts from the menu, or drag it onto a chip and confirm.
- **KalVoice:** scene-aware commands (open or focus threads, terminals, agents, runs and services), follow-ups, agent launch with account, model and effort, and spoken completion and needs-you callbacks.
- **Smaller changes:** KalTidy (stop idle terminals safely), Account Hub, a new account list, thread effort saved across restarts, and closing a pane ends its processes.

Known issues: Gemini CLI is still unavailable. Codex agents can't commit inside their own worktree, so use Commit changes on the agent's card.
